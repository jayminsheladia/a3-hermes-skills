# Privacy Policy: A3 Assistant

Last updated: November 2026

A3 Assistant is a personal course project for CSCI 599 (Agentic AI, Fall 2026). It is not a public service. It connects only to one dedicated test Google account created for the project, and that account holds only made-up test data.

## Google data it accesses

- **Gmail, read-only:** to summarize test emails.
- **Google Calendar events:** to read and, when asked, add test events.
- **Gmail, send:** used only by a separate process, and only after the account owner presses an approval button. It can send only to an allowlisted test address.

## How that data is used and shared

The data is used only to provide the assistant's features to the account owner.

- Calendar details and one-line email summaries may be processed by NVIDIA's hosted AI models.
- Full email text is processed by a model on the owner's own laptop.
- The assistant's messages pass through Telegram.
- Data is stored in a private Google Cloud project.

Data is not sold, used for advertising, or shared with anyone else.

## Retention and deletion

Project data and access tokens are deleted after the course is graded. To revoke access at any time, remove the app at https://myaccount.google.com/permissions.
